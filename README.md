## ⚙️ GitHub Pages の設定手順

1. GitHub リポジトリ（`c1121113/mailet-support`）の **Settings** を開きます。
2. 左メニューの **Pages** を選択します。
3. **Build and deployment** セクションで以下を設定します：
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. **Save** をクリックします。
5. 1〜2分で上記URLにアクセス可能になります。
